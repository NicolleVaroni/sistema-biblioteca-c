# Sistema de Gerenciamento de Biblioteca

Projeto desenvolvido em C para o gerenciamento de livros.

## Funcionalidades

- Cadastro de livros
- Listagem de livros
- Pesquisa por título
- Pesquisa por autor
- Pesquisa por formato
- Edição de livros
- Exclusão de livros
- Salvamento dos dados em arquivo

## Tecnologias utilizadas

- Linguagem C
- Structs
- Vetores
- Manipulação de arquivos
- Funções

## Como executar

Compile o programa:

```bash
gcc main.c -o biblioteca
```

Execute o programa:

```bash
./biblioteca
```
